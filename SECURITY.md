# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub: open the affected repository, go to **Security → Report a vulnerability**, and describe the issue, steps to reproduce, and impact. If private reporting is unavailable for that repository, contact the maintainers via https://www.lncodes.com/.

We will acknowledge the report, investigate, and share a fix or mitigation plan.

## Supported versions

Repositories in this organization are learning examples and small modules. Only the latest commit on the default branch (`main`) is supported.
